## 4. 传播驱动力与下轮优化建议

1. **哪个角色最有效**：孟婆和钟馗是双重杠杆——孟婆解决“倾诉与治愈”，钟馗解决“宣泄与幽默”，二者合占近半数份额并贡献了 70% 的回流新用户。
2. **哪类开场最有效**：具体情境引导（如“最近加班累了”，“遇到了烦心小人”）比宏观哲学发问（“你死后想去哪”）更容易促使用户在 5 秒内开口开麦。
3. **哪类卡片易于分享**：带有高反差、荣誉性或幽默称号的卡片（如“执念深重的生活守夜人”、“涤荡阴霾的浩然判官”）主动分享率超 60%；而纯感伤反思类卡片用户多选择下载自藏。
