## 3. 传播驱动力与阻力归因分析

### 3.1 促成主动分享的驱动因素
1. **角色音色的强共鸣与高辨识度**：钟馗的凛然正气、吸血鬼的颓废高贵、孟婆的超脱释怀，让用户获得显著的“情绪代偿”与“人设表达”需求。
2. **专属色调卡片的视觉吸引力**：1080×1440 竖版卡片具备独特的万圣节暗黑排版，在微信群、Discord 与朋友圈具备高信息密度与分享价值。
3. **免手输码的一键扫码入场**：朋友扫码通过 URL 自动附带有效签名 Token，无阻碍直接开启新会话（P07 的 Discord 分享快速带来 2 名新用户进入）。

### 3.2 阻碍外发的客观因素
1. **情感私密性**：思念、伤痛、职业挫折等深层心理倾诉，用户倾向于下载至手机相册私藏，而非公开发布。
2. **移动端浏览器限制**：微信/小红书内置 WebView 无法直接开麦，需通过顶栏引导点击右上角在系统浏览器打开（P05 经引导后顺利完成）。
