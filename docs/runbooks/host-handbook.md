# 黄泉议会 · 现场主持与大屏操作手册 (Host Handbook)

## 1. 场地与设备拓扑要求

现场主持模式专为 Halloween 线下派对或展台大屏设计，支持观众手持公共麦克风与 7 位来自阴曹地府与西方怪谈的神仙怪物展开全双工实时对话。

```
[现场大屏 / 投影仪] <--- HDMI / AirPlay --- [主持工作台 MacBook (Chrome)]
                                                   |-- USB 音频接口 (外接无线麦克风接收机)
                                                   |-- 3.5mm / 蓝牙立体声音箱 (播放全场背景音乐与神仙语音)
                                                   \-- 极速网络 (推荐稳定 Wi-Fi 或手机热点)
```

- **访问路由**：`https://nether-council.vercel.app/host`
- **准入凭证**：通过 URL 参数 `?token=...` 提供 `HOST_ACCESS_SECRET`，未授权访问自动拦截。

## 2. 仪式准备与设备调优清单

1. **音频权限与全屏沉浸**：
   - 打开 `/host` 页面，点击浏览器地址栏锁头图标，确保“麦克风”权限设为“允许”。
   - 按 `F11` 或 `Control + Command + F` 切换为浏览器全屏模式。
2. **背景音乐（BGM）与智能避让压低（Ducking）检查**：
   - 点击底部控制台左侧 **「幽冥氛围 BGM 开关」**。
   - 对准现场麦克风试音，观察：
     - 当主持人或来宾开口说话时，BGM 音量自动平滑压低约 15.5dB（从增益 0.12 降至 0.02）。
     - 当说话结束时，BGM 平滑淡入恢复原声。
3. **入场二维码投屏验证**：
   - 屏幕左上角常驻展示带有有效活动签名的入场二维码。
   - 用现场手机扫码测试，确保直接跳转进入个人手机端体验页（`/play`），无需任何人工填写口令。

## 3. 现场主持交互标准作业流程 (SOP)

### 步骤一：迎宾与角色开场
1. 观察现场来宾情绪或装扮，在底部控制台选择对应角色（孟婆、黑无常、白无常、钟馗、科学怪人、狼人、吸血鬼）与中英文语言。
2. 将无线麦克风递至来宾，提示：“请看着大屏幕，神仙已经准备好听你的故事了。”
3. 大屏幕实时呈现 32px 高对比度双语字幕与 48 柱音频波形。

### 步骤二：故事互动与引导
- 若来宾短时间紧张无语，主持可参考界面提示的话题开口引导（例如：“跟孟婆聊聊最近加班的累”，“问问钟馗今晚抓了几个小人”）。
- 若来宾讲得过于简短，引导其补充一两句具体细节，避免触发未达结算门槛提示。

### 步骤三：结算身份揭晓与全场庆祝 (All-Hall Celebration)
1. 互动 2~3 分钟后，主持点击底部 **「收好故事 / 结算身份」**。
2. 屏幕中央震撼弹出 1080×1440 专属主题身份卡与千问大模型生成的温暖告别口播。
3. 主持点击底部 **「全场举杯 / 庆祝祝词」**：
   - 现场响起多音和弦钟鸣。
   - 全屏弹出节日横幅并伴随欢呼。
   - 主持举杯引导全场参与者齐声高呼派对口号：“生死之间，人人都有发言权！”

### 步骤四：流转接引下一位来宾 (Next Guest)
1. 结算完成后，主持点击底部蓝色 **「流转下一位」** 按钮。
2. 系统自动执行：
   - 彻底关闭断开上一位来宾的语音长连接与字幕队列；
   - 彻底重置现场历史与身份卡视图，严防上一位故事串入下一位；
   - 接待计数器安全递增（例如：已接待 4 位来宾）。
3. 麦克风用酒精棉片消毒后交由下一位排队观众。

## 4. 应急容灾与异常处置预案

| 异常现象 | 诱因排查 | 主持紧急操作 |
|---------|---------|-------------|
| **大屏提示“语音连接已停止”** | 场地 Wi-Fi 抖动或网络丢包 | 点击控制台「换人重开」，系统将在 2 秒内重新协商建立全新 WebSocket；若频繁发生，切换为主持手机 5G 热点。 |
| **BGM 声音过大盖过神仙说话** | 音频避让增益被系统重置 | 点击两次 BGM 按钮重启音频控制器；或将总音响高音微调降低。 |
| **来宾提前离开 / 拒绝发言** | 社交焦虑或临时离场 | 点击「流转下一位」，清空现场上下文并立刻欢迎下一位观众。 |
| **手机微信扫码打不开麦克风** | 微信内置沙箱 WebView 限制 | 告知来宾根据页面顶部横幅提示，点击右上角「…」选择「在 Safari / Chrome 中打开」。 |
