# 孟婆语音试场

当前提供 G1 浏览器链路和 G2 孟婆 GLB 场景。身份卡、异步双语字幕和其余角色尚未开放。原文字幕不是另一种语言的译文。线上语音可用性先核对 [实施进展](../progress.md)，握手失败不计通过。

## 准备入口

配置与部署参见 README。执行 `pnpm invite:create --url https://nether-council.vercel.app --hours 2`，从被 Git 忽略的 `artifacts/invites/latest.json` 取得中／英文入口。邀请可转发、在签发窗口到期；它不包含厂商密钥，也不代表全局人数或金额封顶。预览地址还需要 Vercel 访问权限。

真人点击开麦并允许权限后才创建付费会话。没有邀请、邀请过期或 `VOICE_ENABLED=false` 时不能建立上游。先用耳机；公共麦克风加现场音响的回声测试应另行记录。

## 真人验收

在目标 Mac Chrome 和 Safari 分别选择中文／英文，讲一件非私人故事，完成至少三次问答。检查原文字幕、真实回复音质与所选语言。孟婆说话时直接开口插话，听她是否立即停播、接住新内容；再试“立即停播”按钮，观察旧响应是否回来。静音后应停止上传麦克风 PCM，恢复后可继续说话。结束或切后台后确认浏览器麦克风指示熄灭。

记录浏览器／系统版本、设备、部署 URL、模型／音色、三轮成功或失败、网络恢复、权限拒绝和匿名错误码。尽量用现场计时记录“停说至听见首音频”“插话至听见停播”；页面折叠的试场测量仅表示从点击开始的连接／首音频到包与 JS 清队列耗时，不能代替上述声学测量。不得提交录音或完整私人故事。

当前最多采集 180 秒，最多重连三次，重连不会延长原会话截止；后台按结束处理，回前台须重新点击。自动化使用模拟麦克风和协议夹具，不计真人通过。真实厂商开场探针只证明开场音频与取消命令，不能计作三轮双工。

匿名结果写入本机 `artifacts/g1-voice/human-YYYYMMDD.json`，汇总仅保留测试项、耗时和错误，不含故事原文。
