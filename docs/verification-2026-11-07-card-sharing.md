# 身份卡会话过期与跨标签页验证 · 2026-11-07

## 复现与修复

原卡片每次切换语言都会请求分享链接，依赖即将过期或被另一标签页覆盖的语音 Cookie。红测复现：VoiceClient 两条入场路径没有保存分享凭证；卡片请求缺少所属会话与凭证，切换语言丢失来源，接口失败仍拼接一个可分享的地址。

修复采用 [ADR 0012](adr/0012-card-sharing-capability.md) 的有界签名凭证：只授权该会话的卡片分享和六类卡片事件；语音与结果权限仍在 235 秒截止。二维码只有公开 invite/ref/character/lang，不含私有分享凭证、故事或昵称。

## 验证记录

- 服务端新增 7 项回归测试修复前全部失败；修复后与原票据、分享、遥测和结果路由合计 28 项通过。
- 服务端覆盖：236 秒后卡片仍可分享、事件仍归属原会话；原语音与结果接口拒绝；A 卡片携带 B Cookie 时仍归属 A；无效或过期凭证不能回退到 B；不同 scope、session、campaign 及被篡改凭证均拒绝。
- 卡片凭证不进入遥测日志或公开链接，公开 referral 不得替代本人的卡片权限。

前端、浏览器及完整检查的最终结果在 PR 中记录。协议桩与缓存结果只用于验证软件边界，不计入真人语音、第二台实体设备、现场声音或真实参与者指标。
