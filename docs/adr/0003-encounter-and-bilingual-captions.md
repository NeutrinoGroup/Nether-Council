# ADR 0003：单角色故事收尾与异步双语字幕

日期：2026-11-01。范围：Gate G3 的 T09/T10。继续使用现有 Next.js、VoiceClient、Qwen 原生 WS、普通 CSS 与服务端文字适配器，不增加数据库或会话框架。

## 故事流程

- 中文／英文各有三个示例。昵称选填，剥离控制与格式字符，限制 24 个 Unicode 码点；仅用于本页称呼，不发送给实时角色或文字模型。
- 角色提示词要求接住用户具体细节，每次最多一个追问，经过 2–3 次用户发言后轻吐槽、暖收尾。此为模型指令，真人语音与内容质量仍须试听；自动化测试不证明幽默质量。
- 只记录确认的非空原文，按话轮 ID、发言者和修订号去重。简单应答、静音和噪声标记不算故事。至少一轮有效表达才可收尾；两轮或已有故事且满 75 秒时提示。这个启发式不等于语义事实校验，T11 仍须验证生成依据。
- 收尾立即结束 WS、撤销麦克风、清空播放和翻译。原始 180 秒采集截止不因重连或提示而刷新。语言切换与进入后台也关闭当前会话，重新开始必须有用户手势。
- 草稿最多 16 条确认话轮，每条最多 600 字符，仅留客户端内存；刷新、新开聊或切换语言后消失，不进入 localStorage、URL 或日志。T11 必须把客户端草稿视作不可信输入，重新验证会话、来源与结果 schema。本轮不生成身份、确定结果口播或卡片，不发送“完成身份”的漏斗事件。

## 异步翻译

- 中继先发送原文，音频路径不 await 翻译；双方确认话轮各启动一个短文本任务。角色以 `response.done` 确认为界，用户以 ASR completed 为界；未完成片段不调用文字模型。
- 使用账号所属千问兼容端点、`qwen3.6-flash`、JSON 输出、关闭思考；独立 `QWEN_TEXT_API_KEY` 优先，空值沿用语音密钥。配置仅在服务端读取。接口依据：[千问文字 API](https://platform.qianwenai.com/docs/api-reference/chat/openai-chat)。
- 一条 WS 同时最多两个未完成任务（双方各一个），新原文／修订会取消该发言者旧任务；单段源文最多 1200 字符，译文最多 3000 字符，HTTP 响应体最多 32 KiB。每次请求 1800ms、失败最多再试一次，连无视 abort 的迟到 Promise 也不能延长可见等待。
- 每条 WS 最多提交 24 个翻译任务，每任务最多两次请求；最多三次语音重连意味着单体验理论上最多 96 个任务／192 次请求。这是有界连接预算，不是跨实例或全局额度；账户配额及紧急开关仍必需。
- `caption.translation` 独立事件携带完整原文身份。客户端逐一核对 sessionId、epoch、responseId、segmentId、revision、speaker、sourceLocale、sourceText；仅补到当前已确认原文，不让译文创建原文。新响应先发送 `response.started` 清理旧角色字幕。
- VAD、新响应、手动打断、断线、停止和语言切换使相应任务失效。推理已结束但仍在播放的回复也可取消翻译；迟到的旧取消不能终止新回复。服务端同样根据最新用户 item_id 拒绝上一轮迟到 ASR。
- 超时、无配置、超长、预算耗尽或结构错误均降级为“译文暂不可用”，原文和语音保持可用；不记录原始厂商错误、转写或凭据。界面使用 React 文本节点，不解释模型输出的 HTML。

## 验证与边界

Vitest 覆盖倒计时、去重、无故事、草稿、语言／连接隔离、翻译队列、硬超时、预算和 JSON 响应限制；真实本机 WS 夹具验证翻译未完成时音频仍下发以及取消／VAD／关闭失效。Playwright 在桌面和手机视口检查实际 Worklet、字幕、收尾、语言切换和可达操作。

4 条合成故事通过真实 `qwen3.6-flash` 翻译：中文到英文 620/682ms，英文到中文 430/638ms，均首次请求成功。报告 `artifacts/g3-captions/text-smoke.json`（本机忽略）；这不是延迟 P95、真人三轮、手机实机或完整 G3 验收。最终检查结果及预览证据记录在 `docs/progress.md`。
