# ADR 0006: 现场主持大屏大字双语字幕、BGM 避让压低与全场祝词狂欢

## 状态

已实施 (Accepted)

## 背景

万圣节黄泉议会派对不仅支持宾客手机端自主对聊，更需要为线下聚会现场提供主舞台/投影仪大屏主持模式（Host Mode）。
根据任务规范 T15（Gate G4）：
1. 现场主持大屏路由 `/host`，支持全场常驻进场二维码、来宾序号流转与即时大字号双语字幕。
2. 背景环境音乐（BGM）智能闪避（Ducking）：角色说话或现场持麦说话时音量平滑下调 ~15dB，静音或停顿后平滑回弹。
3. 角色与语言现场即时切换，无缝重连，防串线清理。
4. “下一位”（Next Guest）一键转场流转：安全断开当前音频轮、重置会话计时与状态机、递增来宾计数器。
5. 全场举杯/祝词狂欢（All-Hall Celebration）：支持主持人一键触发或每接待 4 位来宾时智能 Toast 提示，伴随 Web Audio 和弦钟鸣与全屏狂欢横幅。

## 架构决策

1. **主持会话鉴权与大屏舞台视图 (`HostStage.tsx`)**:
   - 路由 `/host` 校验专用主持凭证 `HOST_ACCESS_SECRET`（或通过安全链接参数快速入场）。
   - 布局采用主客分栏大字投影界面：左侧置入 3D 角色舞台与 48 段音频能量频段，右侧呈现超大字号（32px）即时角色台词与现场发言字幕。
   - 顶部常驻现场扫码牌，动态生成指向 `/play?invite=...` 的高对比度专属入场二维码。

2. **Web Audio API 合成音效与平滑增益控制 (`bgm.ts` / `celebration.ts`)**:
   - `BgmController` 基于浏览器原生 `AudioContext`，无需下载庞大外部 mp3 资源即可生成幽幽冥界氛围环境低音，并通过 `GainNode` 的 `linearRampToValueAtTime` 实现毫秒级平滑过渡：
     - 常态背景增益：`0.12`
     - 话轮避让增益：`0.02`（下降 ~15.5dB）
   - `playCelebrationChime` 使用两段式正弦和弦合成器演奏清脆明快的万圣节狂欢进场音。

3. **主持人中控台与响应式适配 (`globals.css`)**:
   - 底部固定半透明毛玻璃中控台（`.host-control-deck`），聚合角色选择片区、中英语言切换片区及关键操作流（开启麦克风、立即停播、下一位来宾、全场祝词、BGM 开关）。
   - 适配大屏投影、桌面主持及移动端手机遥控多种视口，在 900px 以下自动折叠为单列触摸卡片与水平防溢流横滑滚槽，确保按钮点击绝不遮挡或互斥。

4. **状态流转与身份即时揭晓**:
   - 支持话轮充实后直接在投影大屏触发 `claim` 并实时渲染 1080×1440 身份大卡，支持下载与全场展示。
   - 切换来宾时执行彻底析构清理（`stop("next_guest")`），确保上一位客人的音频采样与连接完全释放。
