产品边界以 [spec.md](spec.md) 为准，接口与目录以 [plan.md](plan.md) 为准。所有任务初始未完成；没有实际报告与可复现证据不打勾。活动日期未指定，按依赖闸门推进，不承诺旧 issue 的 24 小时工期。

- [x] T01 核对语音、文字、3D 三条实际接入路径。确认 Qwen 指定实时模型鉴权、文字模型权限、官方端点；确认混元账号所属平台与 GLB 导出。配置报告只列变量名和结果，不包含值。
- [x] T02 初始化轻量 pnpm workspace：`apps/web`、`packages/contracts`、`packages/party-core`。锁定 Next.js／React／R3F 兼容版本，配置环境文件忽略、占位示例和所需命令。
- [x] T03 建立 Vercel 预览部署，核对 Fluid Compute、所选套餐的 WS／时限／限流能力、仓库连接权限及日志采集。用两个事件验证“客户端 → 服务端日志 → 本机采集 → 去重报告”；说明采集盲区。

通过条件：预览 HTTPS 可访问，真实厂商配置有可调用或可导出的证据，采集链路可用；模型访问失败时记录具体错误，不擅自换成别的模型宣称通过。

## G1 一个真实全双工角色

依赖 G0。先做孟婆，无需等待其他角色资产。

- [x] T04 定义 Session／Character／Caption／Result／Error 的 schema、应用 WS 协议及状态机。实现票据、连接归属、超时与清理；为非法转换、跨 session 事件和重连延长时限写有效测试。
- [x] T05 跑通浏览器 AudioWorklet → 重采样 → PCM → Vercel 中继 → Qwen → 24kHz 流式播放。实现原文字幕与连接错误状态。
- [ ] T06 实现插话停播、旧音频清理、过期事件隔离、静音与恢复、最大 3 次重连。真实麦克风完成中文／英文各 3 轮，并记录停播与首音频延迟。

通过条件：部署环境真人能听到真实回复、随时插话、继续交流，麦克风在 AI 播放期间保持上传。不能用合成音频播放或按键说话代替双工。

证据：版本、预览 URL、所选模型／音色、匿名时间测量、真人试听记录与错误列表。报告存本机 `artifacts/g1-voice/`，可提交不含敏感内容的摘要。

## G2 一个真实 3D 模型

依赖 G0；G1 未通过前，不批量生成其余六位。

- [x] T07 使用混元生成孟婆模型并保存 GLB、海报、来源记录与哈希。验证实际精度、形象、材质、大小与加载；确认哪些节点可动画，确定独立嘴部／眼部方案。
- [ ] T08 在 Next.js 客户端场景中加载 GLB，实现 idle／听／说／庆祝状态和实际播放 RMS 驱动嘴部。在目标 Mac 与一台手机连续运行 2 分钟，记录 FPS、加载与资源占用。

通过条件：真实 GLB 在浏览器正确显示，音频播放与嘴部同步，停播后嘴部停止，达到 spec 性能目标。占位几何体只可用于开发，不算生成模型验收。

- [x] T10 实现异步双语字幕及失效机制；验证译文延迟不会阻塞语音，旧话轮／角色翻译不会覆盖当前字幕。
- [x] T11 实现经过 schema 校验的双语身份生成、确定结果的暖收尾口播、本地结果缓存与重试隔离。无有效故事不伪造专属结果。

通过条件：中文与英文各完整跑通一次“入口 → 真人对话 → 身份卡 → 第二台设备扫码开聊”。卡片内容与用户故事相关，口播与卡片身份一致，传播指标可以实证。

- [x] T17 在 Mac Chrome／Safari、iPhone Safari、Android Chrome 检查权限、播放、插话、字幕、卡片下载及扫码；记录微信／小红书内置浏览器入口表现与外部浏览器指引。
- [x] T18 完成 DNS 与正式域名、签名活动邀请与主持凭证、服务端限额／紧急开关、匿名日志采集、设备音量预检和部署后 smoke。验证朋友扫码无需手填码，过期邀请与关闭额度不能建付费连接。所有指标写实际结果。

## 任务完成与变更规则

每项记录实现范围、验证命令、实际结果、证据位置和剩余问题；架构变化更新 ADR，行为变化更新 spec 与相应 tests／evals。任务可以拆成独立 PR，但只在需要时增加 worktree／Agent；本清单不代表已创建 issue、PR 或自动执行。

需要外部资源的阻塞应明确写成“账号不具备某模型权限”“GLB 未达到预算”“现场设备回声测试失败”等可复验事实。不能通过删除验收项、换为 Mock 或改写报告来完成任务。
